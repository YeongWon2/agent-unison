# 동기화 계획

Agent Unison의 현재 기능은 동기화 계획 수립이다. 실행 엔진과 `sync`, `apply`, `rollback` 명령은 아직 없다. 이 명령을 실행하거나 설치할 수 있다고 안내하지 않는다.

사용자가 지정한 범위에서 다음을 확인한다.

1. 한 기기인지 여러 기기인지, 프로젝트 파일인지 사용자 전역 파일인지 확인한다. 범위가 이미 정해졌다면 반복해서 묻지 않는다.
2. 선택한 스킬·지침·참고 문서를 읽고 원본 경로, 사용 도구, 참조 파일, 도구 전용 지시를 기록한다. 요청 범위 밖의 홈 디렉터리 전체나 인증·대화 이력을 수집하지 않는다.
3. 공통으로 유지할 내용과 도구별로 남길 내용을 구분한다. 파일이 같아도 로드 위치·메타데이터·지시 해석이 같다고 단정하지 않는다.
4. 공통 원본에서 두 도구용 파일을 만드는 방식과 기존 한쪽을 원본으로 쓰는 방식을 비교한다. 충돌·누락 참조·실행 의존성과 수동 결정이 필요한 항목을 표시한다.
5. 제안하는 원본과 대상 경로, 예상 변경, 검증 방법, 미확정 결정을 사용자에게 보여준다. 파일에 계획을 저장하라는 요청이 있으면 지정한 위치에 저장한다.

조사 중에는 대상 스킬·지침·설정을 수정하지 않는다. 스킬에 포함된 스크립트나 명령도 조사 목적으로 실행하지 않는다. 실제 적용을 요청받으면 현재 자동 적용 기능이 없음을 밝히고, 별도의 명시된 수동 변경 작업으로 범위와 검증 방법을 정한다.
